# سجل تغييرات النسخة المدمجة

## النسخة النهائية المرفوعة إلى `main`

تجمع هذه النسخة تحديثات الواجهة والخلفية وخدمة الصور المرفقة مع المستودع الأساسي. يحافظ الدمج على فصل Laravel وReact وFastAPI بدل نسخ الملفات إلى جذر موحد غير قابل للتشغيل.

| المجال | التغيير |
|---|---|
| Laravel API | تحديث متحكمات المستخدم والإدارة والتصاميم والطلبات والكوبونات والعرض وOAuth، مع تحديث `routes/api.php`. |
| التحقق والاستجابات | إضافة Form Requests وAPI Resources لتوحيد قواعد الإدخال وبنية البيانات المرتجعة. |
| الأحداث والإشعارات | إضافة أحداث ومستمعات للتصميمات والطلبات والكوبونات وتغييرات المستخدمين وحالات الطلب. |
| الواجهة | تحديث `Dashboard` و`LandingPage` و`AdminDashboard` وعميل API ومدير العرض واختبار Ping. |
| Google OAuth | إضافة مكون `GoogleLoginButton` وإضافة اعتماد `@react-oauth/google` إلى manifest وlockfile الواجهة. |
| خدمة الصور | تحديث `image_generator.py` لدعم تحسين دمج الشعار والصورة الشخصية وزوايا العرض وحقول حالة صريحة. |
| قاعدة البيانات | إضافة `AdminSeeder` وتحديث `DatabaseSeeder`؛ لم تُضف لقطة SQLite المحلية إلى Git. |
| HTML العام | تحديث `frontend/public/index.html` بعنوان عربي وpreloader وهوية Styloraify. |
| الأمان | تنظيف قواعد `.gitignore` وحماية ملفات البيئة ومخرجات البناء وقواعد SQLite وذاكرة Python المؤقتة. |
| التوثيق | استبدال README المؤقت وإضافة أدلة المعمارية والتشغيل والتحقق وسجل التغييرات. |

## تصحيحات قابلية الصيانة

كانت ثلاثة ملفات Form Request في المرفقات تحمل أسماء لا تطابق الأصناف المعلنة أو الاسم القياسي للملف. عُدلت أسماء الملفات قبل الدمج لتطابق PSR-4، من دون تغيير اسم namespace أو class داخلها.

| الاسم المرفق | الاسم المعتمد |
|---|---|
| `UpdateOrderStatusRequest .php` | `UpdateOrderStatusRequest.php` |
| `UpdateUserLimitRequest.php.php` | `UpdateUserLimitRequest.php` |
| `Web/LoginRequest.php.php` | `Web/LoginRequest.php` |

## حدود مقصودة

لم تُنفذ عمليات توليد صورة فعلية أو Google OAuth فعليًا، لأن ذلك يحتاج مفاتيح ونطاقات وحسابات اختبار لا ينبغي رفعها إلى المستودع. كما لم تُحدّث حزم الواجهة القديمة بصورة قسرية أثناء هذا الدمج. يوضح [`VERIFICATION.md`](VERIFICATION.md) اختبارات القبول المطلوبة قبل أي نشر إنتاجي.
